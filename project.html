Industrial Project — Medical Record Summarization
This project was developed in collaboration with a Parisian hospital. The goal was to summarize large volumes of medical records and extract key patient information from complex clinical documents.

The main objective was to achieve strong recall across several medical categories, including medical history, lifestyle information, surgical history, treatments, and biometric data. The project focused on helping healthcare professionals access important patient information more quickly and reliably.

My work involved understanding the structure of medical documents, identifying relevant information categories, and contributing to the design of a solution adapted to real hospital data.

Data Analysis — Credit Risk Prediction
This project focused on data analysis and prediction using the German Credit dataset. The objective was to study customer data and build a model capable of predicting whether a person was likely to repay their credit or not.

We worked on data exploration, data preprocessing, feature analysis, and predictive modeling in order to better understand the factors influencing credit repayment. The project also included the interpretation of results and the evaluation of model performance.

We produced a detailed report presenting our methodology, our analysis of the dataset, the prediction results, and the main conclusions drawn from the project.

Perfume Recommendation Web App
This project consisted of building a web application designed to recommend the most suitable perfume to a user through an incremental elicitation process.

The application asks the user a series of questions and progressively refines their preferences in order to identify the perfume that best matches their taste. We implemented decision-making algorithms such as Minimax Regret and designed the incremental elicitation process used to guide the recommendation.

The project was developed as a React web application, combining algorithmic decision support with an interactive user experience.

High Performance Computing — Cryptographic Key Cracking
This project focused on high performance computing and cryptographic key cracking using hash functions. The goal was to design and optimize a system capable of recovering cryptographic keys as efficiently as possible.

We implemented a meet-in-the-middle attack and worked on improving the performance of the algorithm while managing important technical constraints such as memory usage and computation time.

This was a highly challenging project, as the objective was to crack the largest possible key size. Our implementation successfully handled keys up to 40 bits, requiring careful optimization and efficient resource management.
